# Lapka Motors — этап 3

Настольное приложение Windows на Python, CustomTkinter и SQLite.

Установка:
```powershell
py -m pip install -r requirements.txt
```

Запуск:
```powershell
py -m app.main
```

База данных хранится в `data/lapka_auto.db`. Перед заменой файлов старого проекта скопируйте свою базу 
данных в безопасное место. Этот этап сохраняет существующую базу, если она находится по этому пути.

Реализовано: тёмный интерфейс с бежевыми акцентами, боковая навигация, главная страница, гараж, 
добавление автомобилей, изменение пробега, журнал обслуживания и напоминания по дате/пробегу. Фотографии 
автомобилей и системные уведомления Windows — следующие этапы.
